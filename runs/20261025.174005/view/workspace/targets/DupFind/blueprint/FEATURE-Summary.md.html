FEATURE: Summary

FieldValue
Version20261025 V1
DescriptionWrite the one-row CSV summary of groups, duplicate files, and reclaimable bytes when --summary is given.
Depends OnFEATURE-Listing.md, ARCHITECTURE.md
Providesreport.WriteSummary
Consumesdupes.Order

Purpose

With --summary the tool reports the totals of the listing that the same options would produce, instead of the listing itself.

Interface

report.WriteSummary writes, through encoding/csv with \n line endings, the header groups,duplicate_files,reclaimable_bytes and one row:

  • groups: the number of duplicate groups.
  • duplicate_files: the sum of files - 1 over all groups.
  • reclaimable_bytes: the sum of every group's size x (files - 1).

With no duplicates the row is 0,0,0. The --summary mode of cli.Run uses the same walk, grouping, and ordering as the listing, with the same --min-size, and returns 0.

Reads and Writes

  • Reads: ordered groups.
  • Writes: CSV to standard output only.

Programmatic Acceptance

=== AC summary-totals-match-fixture ===
Intent: The summary row equals totals computed from the fixture's known duplicate structure.

import csv import os import tempfile from drydock_go import cli_runner

def write(root, rel, data): p = os.path.join(root, rel) os.makedirs(os.path.dirname(p), exist_ok=True) with open(p, "wb") as f: f.write(data)

fixtures = { b"quarterly report\n": ["a/r.txt", "b/r2.txt", "c/r3.txt"], b"la la la\n": ["m/s.mp3", "m/s2.mp3"], b"unique content here\n": ["u/solo"], } dup_groups = [(c, p) for c, p in fixtures.items() if len(p) > 1] want_groups = len(dup_groups) want_files = sum(len(p) - 1 for c, p in dup_groups) want_bytes = sum(len(c) * (len(p) - 1) for c, p in dup_groups) with tempfile.TemporaryDirectory() as root: for content, paths in fixtures.items(): for p in paths: write(root, p, content) code, out, err = cli_runner("--summary", root) print(out) print(err) assert code == 0 rows = list(csv.reader(out.splitlines())) assert len(rows) == 2 assert rows[0] == ["groups", "duplicate_files", "reclaimable_bytes"] assert [int(x) for x in rows[1]] == [want_groups, want_files, want_bytes] === END AC summary-totals-match-fixture ===
