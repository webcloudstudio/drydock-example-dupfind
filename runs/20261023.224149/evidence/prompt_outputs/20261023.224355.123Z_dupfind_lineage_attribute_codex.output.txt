<requirement name="go-application-structure" stories="architecture">
Implement in Go 1.22 or newer using only the standard library. The application root is a Go module, and its executable is the main package at `./cmd/dupfind`. Tests run under `go test`.
</requirement>
<requirement name="parse-command-options" stories="cli-options">
dupfind [--summary] [--min-size &lt;bytes&gt;] &lt;directory&gt;
</requirement>
<requirement name="validate-scan-directory" stories="directory-validation">
The tool walks &lt;directory&gt; recursively, including hidden files and directories
(names beginning `.`).
</requirement>
<requirement name="discover-eligible-files" stories="file-discovery">
It considers regular files only. It neither follows nor reports symbolic links.
</requirement>
<requirement name="group-duplicate-files" stories="file-hashing">
Files are grouped by size first. Only files that share a size are read.
Within a size, files are grouped by the SHA-256 digest of their contents. A group of two or
more files with the same size and digest is a duplicate group.
</requirement>
<requirement name="emit-listing-report" stories="listing-report">
Listing (default): header `group,size,sha256,path`, then one row per file in every duplicate
group.
</requirement>
<requirement name="emit-summary-report" stories="summary-report">
Summary (`--summary`): header `groups,duplicate_files,reclaimable_bytes`, then one row.
</requirement>
<requirement name="run-test-and-vet-gate" stories="test-gate">
The completed application provides a POSIX-compatible `bin/test.sh` that runs
`go vet ./...` and `go test ./...` from the application root and exits zero only when both pass.
</requirement>
<requirement name="pass-conformance-suite" stories="conformance">
The harness runs `go build -o &lt;temporary path&gt; ./cmd/dupfind`, creates a fixed directory tree in a
temporary directory, and then runs 15 checks.
</requirement>
