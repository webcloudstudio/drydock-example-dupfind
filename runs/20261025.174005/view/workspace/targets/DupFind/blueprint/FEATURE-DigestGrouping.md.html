FEATURE: Digest Grouping

FieldValue
Version20261025 V1
DescriptionHash same-size files with SHA-256 and form duplicate groups, skipping unreadable files with a stderr warning.
Depends OnFEATURE-SizeGrouping.md, ARCHITECTURE.md
Providesdupes.GroupByDigest
Consumesdupes.GroupBySize

Purpose

Rule 3 groups same-size files by the SHA-256 digest of their contents; a group of two or more files with the same size and digest is a duplicate group. Rule 6 skips unreadable files with one warning.

Interface

dupes.GroupByDigest takes the size buckets from dupes.GroupBySize. For each bucket it opens each file read-only and streams it through crypto/sha256. The digest is the lowercase hexadecimal encoding of the full contents. Files with identical size and digest form one group; groups with a single member are dropped.

A file that cannot be opened or read yields exactly one warning line on standard error, is excluded from grouping, and does not change the exit code. Files are opened read-only; nothing is written, moved, or deleted under the examined directory.

Reads and Writes

  • Reads: the contents of files in shared-size buckets.
  • Writes: warning lines to standard error only.

Required Project Tests

internal/dupes contains TestGroupByDigest (identical contents group, same-size different contents do not) and TestGroupByDigestSkipsUnreadable (an unreadable file is skipped with one warning and does not fail the call).

=== AC digest-tree-unmodified ===
Intent: Running the tool leaves every file's bytes and the directory listing unchanged.

import os import tempfile from drydock_go import cli_runner

def write(root, rel, data): p = os.path.join(root, rel) os.makedirs(os.path.dirname(p), exist_ok=True) with open(p, "wb") as f: f.write(data)

def snapshot(root): snap = {} for dirpath, dirnames, filenames in os.walk(root): for n in filenames: p = os.path.join(dirpath, n) with open(p, "rb") as f: snap[os.path.relpath(p, root)] = f.read() for n in dirnames: snap[os.path.relpath(os.path.join(dirpath, n), root) + "/"] = None return snap

content = b"keep me\n" with tempfile.TemporaryDirectory() as root: write(root, "a/f1", content) write(root, "b/f2", content) write(root, "c/other", b"different!") before = snapshot(root) code, out, err = cli_runner(root) print(out) print(err) assert code == 0 code, out, err = cli_runner("--summary", root) assert code == 0 assert snapshot(root) == before === END AC digest-tree-unmodified ===
