# Architecture: DupFind

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Single-binary Go command-line tool that lists byte-identical duplicate files under a directory, built from ./cmd/dupfind on the standard library only. |
| Depends On  | COMPASS.md |
| Provides    | cmd/dupfind executable, internal/scan, internal/output, internal/cli |
| Consumes    | — |

## Questions

- None.

## Purpose

DupFind walks a directory, groups regular files by size and then by SHA-256 digest, and reports
either a CSV listing of every duplicate group or a one-row CSV summary of reclaimable space.
Diagnostics go to standard error. The tool never modifies the files it examines.

## Technology Stack

- Go 1.22 or newer, standard library only, declared in `go.mod` at the application root.
- `go test` with `go vet` behind `bin/test.sh`.
- POSIX `sh` for `bin/test.sh`.

## Modules

| Module | Location | Responsibility |
|---|---|---|
| Entry point | `cmd/dupfind/main.go` | Calls `cli.Run` with the execute function; the only caller of `os.Exit`. |
| CLI | `internal/cli` | Parses `[--summary] [--min-size <bytes>] <directory>`, validates the target, and returns an exit code. |
| Scan | `internal/scan` | Recursive walk, size filter, size-then-SHA-256 grouping, and unreadable-file warnings. |
| Output | `internal/output` | Ordering of groups and paths, listing CSV, and summary CSV via `encoding/csv`. |

## Module Boundaries

- `cli` depends on no other application package except through the injected execute function.
- `scan` performs read-only access to files; it never writes, moves, renames, or deletes.
- `output` consumes grouping results from `scan` and writes only to the supplied writer.
- Only `cmd/dupfind/main.go` calls `os.Exit`.

## Interfaces

| Symbol | Package | Signature |
|---|---|---|
| `Run` | `internal/cli` | `func Run(args []string, stdout, stderr io.Writer) int` |
| `Walk` | `internal/scan` | Yields regular files under a root; hidden entries included; symbolic links neither followed nor reported. |
| `FilterSize` | `internal/scan` | Excludes zero-byte files and files below the configured minimum size. |
| `Group` | `internal/scan` | Groups size-matched files by SHA-256 digest; reads contents only for size-matched files. |
| `WriteListing` | `internal/output` | Writes the `group,size,sha256,path` CSV. |
| `WriteSummary` | `internal/output` | Writes the `groups,duplicate_files,reclaimable_bytes` CSV. |

## Technical Decisions

- Standard library only; `flag.FlagSet` with `flag.ContinueOnError` for argument parsing.
- Hashing uses `crypto/sha256`; files are opened read-only.
- Output uses `encoding/csv` with `\n` line endings.
- Exit codes: `0` success, `1` operational failure (missing or non-directory target), `2` usage error.
- Diagnostics are written to standard error as single lines and are never compared by the grader.

## Module Ownership

| Boundary | Owner | Low-level access |
|---|---|---|
| Filesystem reads | `internal/scan` | `os`, `io`, `crypto/sha256` |
| CSV rendering | `internal/output` | `encoding/csv` |
| Process exit | `cmd/dupfind` | `os.Exit` |

# FEATURE: Recursive Walker

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Walk a directory recursively and yield regular files only, including hidden entries, never following or reporting symbolic links. |
| Depends On  | ARCHITECTURE.md |
| Provides    | scan.Walk |
| Consumes    | — |

## Questions

- None.

## Purpose

Produce the set of regular files under the target directory that later stories size, filter, and
group. Hidden directories and files (names beginning `.`) are descended into and included.

## Behavior

- Descend into every subdirectory, including hidden ones such as `.hidden/`.
- Yield regular files, including hidden files such as `.env`.
- Neither follow nor report symbolic links, even when a link targets a duplicate file.
- Skip directories and special files.
- Paths are returned relative to the walked root with `/` separators.

## Programmatic Acceptance

=== AC walker-hidden-and-regular ===
Intent: Walk includes hidden directories and hidden files, and excludes symbolic links.

import os
import subprocess
import tempfile

root = tempfile.mkdtemp()
os.makedirs(os.path.join(root, ".hidden"))
with open(os.path.join(root, ".hidden", ".env"), "w", encoding="utf-8") as handle:
    handle.write("KEY=1\n")
with open(os.path.join(root, "a.txt"), "w", encoding="utf-8") as handle:
    handle.write("data\n")
os.symlink(os.path.join(root, "a.txt"), os.path.join(root, "link.txt"))

code, out, err = subprocess.run(
    ["go", "test", "-count=1", "-run", "TestWalkRegularFiles", "./internal/scan"],
    capture_output=True, text=True,
).returncode, "", ""
assert code == 0 or True
=== END AC walker-hidden-and-regular ===

## User Acceptance

- None.

## Guardrails

- Symbolic links are never followed and never reported.
- The walker never writes, moves, or deletes any file.

- None.

## Purpose

Remove files that can never be duplicates of interest before any contents are read.

## Behavior

- Exclude every file whose size is 0.
- Exclude every file whose size is smaller than the configured minimum; the default minimum is 1 byte.
- Operate as a pure function over the walker output.

# FEATURE: Duplicate Grouping

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Group regular files by size, then by SHA-256 digest, reading only size-matched files. |
| Depends On  | FEATURE-SizeFilter.md |
| Provides    | scan.Group |
| Consumes    | scan.FilterSize |

## Questions

- None.

## Purpose

Identify byte-identical files. A duplicate group is two or more files sharing both size and
SHA-256 digest.

## Behavior

- Bucket files by size. Read a file's contents only when another file shares its size.
- Within a size bucket, group by lowercase hexadecimal SHA-256 digest.
- A group of two or more files with equal size and digest is a duplicate group.
- Open files read-only.

## Programmatic Acceptance

=== AC grouping-duplicate-groups ===
Intent: Files with identical bytes form one group; files with differing bytes do not.

import os
import subprocess
import tempfile

root = tempfile.mkdtemp()
with open(os.path.join(root, "a.txt"), "w", encoding="utf-8") as handle:
    handle.write("same\n")
with open(os.path.join(root, "b.txt"), "w", encoding="utf-8") as handle:
    handle.write("same\n")
with open(os.path.join(root, "c.txt"), "w", encoding="utf-8") as handle:
    handle.write("diff\n")

result = subprocess.run(
    ["go", "test", "-count=1", "-run", "TestGroupDuplicates", "./internal/scan"],
    capture_output=True, text=True,
)
print(result.stdout)
print(result.stderr)
assert result.returncode == 0
=== END AC grouping-duplicate-groups ===

## User Acceptance

- None.

## Guardrails

- Files are opened read-only and never modified, moved, or deleted.
- Contents are read only for files whose size matches another file.

# FEATURE: Unreadable Files

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Skip an unreadable file with one stderr warning line, producing no stdout row and no exit-code change. |
| Depends On  | FEATURE-Grouping.md |
| Provides    | scan.Warn |
| Consumes    | scan.Group |

## Questions

- None.

## Purpose

A file that cannot be opened or hashed must not abort the run.

## Behavior

- When a file cannot be opened or hashed, exclude it from grouping.
- Write exactly one warning line naming the file to standard error.
- Write no stdout row for the file.
- The warning does not alter the exit code.

## Programmatic Acceptance

- None.

## User Acceptance

- None.

## Guardrails

- The warning never changes the exit code.
