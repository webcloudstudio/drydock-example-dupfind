## Overview

DupFind is a Go command-line application with one executable at `./cmd/dupfind`. The root Go module uses Go 1.22 or newer and the standard library only.

## Modules

| Module | Responsibility |
|---|---|
| `cmd/dupfind` | Process entry point; calls the CLI runner and exits with its returned status. |
| `internal/cli` | Parses arguments, validates the requested directory, coordinates discovery and output, and maps failures to exit codes. |
| `internal/duplicate` | Walks the requested directory, filters regular files, groups candidates by size and SHA-256 digest, and orders duplicate groups. |
| `internal/output` | Writes listing and summary CSV through `encoding/csv`. |
| `bin/test.sh` | Runs `go vet ./...` followed by `go test ./...`, stopping on failure. |

The command reads examined files only. It does not modify, delete, or move files under the requested directory.

## Module ownership

| Boundary | Owner | Allowed access |
|---|---|---|
| Persistence | None | The application has no persistent state. |
| Configuration | `internal/cli` | Command-line options only; no configuration store. |
| File discovery and reads | `internal/duplicate` | Read-only directory traversal and file reads for hashing. |
| External services | None | The application uses no external service. |

## Technology Stack

| Technology | Application |
|---|---|
| Go | Go 1.22 or newer; implementation and executable. |
| Go standard library | File traversal, SHA-256, CSV, flags, and tests. |
| POSIX shell | `bin/test.sh` quality-check launcher. |

# FEATURE: Duplicate Finding

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Finds duplicate regular files and emits a listing or summary as CSV. |
| Depends On  | ARCHITECTURE.md |
| Provides    | dupfind command |
| Consumes    | ./cmd/dupfind |

## Questions

- None.

## Purpose

Find byte-identical regular files recursively beneath one requested directory and report each duplicate group, or summarize the reclaimable space. The tool never deletes, moves, or modifies examined files.

## Command

```text
dupfind [--summary] [--min-size <bytes>] <directory>
```

Options precede the directory, and exactly one directory argument is required.

| Option | Behavior |
|---|---|
| `--summary` | Write summary CSV instead of listing CSV. |
| `--min-size <bytes>` | Ignore files smaller than a positive integer byte count; defaults to 1. |

Unknown options, missing option values, invalid or nonpositive minimum sizes, a missing directory argument, and extra arguments are usage errors.

## Discovery and grouping

Walk the directory recursively, including hidden files and directories. Consider regular files only; do not follow or report symbolic links. Ignore zero-byte files. First group eligible files by size and read contents only for sizes shared by at least two files. Hash those contents with SHA-256 and report only groups with at least two matching files.

A file that cannot be read is skipped, with one warning line on standard error for that file. Continue processing and return success.

Paths are relative to the requested directory, use `/` separators, and have no leading `./`. Within each duplicate group, sort paths by byte value ascending. Order groups by reclaimable bytes descending, then by lowercase hexadecimal SHA-256 digest ascending. Reclaimable bytes equal file size multiplied by the number of copies beyond the first. Number groups from 1 in that order.

## Output

Use Go's `encoding/csv` writer and newline-terminated CSV on standard output.

Listing CSV has header `group,size,sha256,path`, followed by one row per file in each duplicate group. A group has one shared group number, size, and lowercase hexadecimal digest across its rows. If no duplicates are found, write only the header.

Summary CSV has header `groups,duplicate_files,reclaimable_bytes` and one data row. Groups count the selected duplicate groups; duplicate files sum the number of copies beyond one per group; reclaimable bytes sum the groups' reclaimable bytes. With no duplicates, the data row contains zero for all three totals. The same minimum-size option selects groups for listing and summary.

Any command failure writes no standard output and one diagnostic line to standard error. A missing or non-directory path exits 1. Malformed or missing/extra arguments exit 2. Successful operation exits 0, whether or not duplicates are found.
