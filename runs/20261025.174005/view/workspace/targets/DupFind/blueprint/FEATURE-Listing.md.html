DescriptionWrite the CSV duplicate listing with header group,size,sha256,path using encoding/csv and wire the default mode of cli.Run.

Consumesdupes.Order

Purpose

The default output of dupfind <directory> is a CSV listing of every file in every duplicate group.

Interface

report.WriteListing writes to standard output through encoding/csv with \n line endings (UseCRLF false). The header row is group,size,sha256,path. One row follows per file of every ordered group: group number, size in bytes, lowercase hexadecimal SHA-256, relative path. With no duplicates only the header is written. Fields containing a comma, a double quote, or a newline are quoted as RFC 4180 specifies, by the csv writer.

The default (non-summary) mode of cli.Run runs the walk, size grouping, digest grouping, and ordering with the configured --min-size, then this writer, and returns 0. --min-size excludes files smaller than the given number of bytes.

Reads and Writes

  • Reads: ordered groups.
  • Writes: CSV to standard output only.

Intent: The entire standard output equals the CSV the standard csv writer produces from the fixture-derived rows.

import csv import hashlib import io import os import tempfile from drydock_go import cli_runner

def write(root, rel, data): p = os.path.join(root, rel) os.makedirs(os.path.dirname(p), exist_ok=True) with open(p, "wb") as f: f.write(data)

fixtures = { b"alpha alpha\n": ["a/one.txt", "b/two.txt", "c/deep/three.txt"], b"beta\n": [".hidden/.env", "env.bak"], } header = ["group", "size", "sha256", "path"] groups = [] for content, paths in fixtures.items(): groups.append((len(content) * (len(paths) - 1), hashlib.sha256(content).hexdigest(), len(content), sorted(paths))) groups.sort(key=lambda g: (-g[0], g[1])) buf = io.StringIO() w = csv.writer(buf, lineterminator="\n") w.writerow(header) for n, g in enumerate(groups, start=1): for p in g[3]: w.writerow([n, g[2], g[1], p]) expected = buf.getvalue()

with tempfile.TemporaryDirectory() as root: for content, paths in fixtures.items(): for p in paths: write(root, p, content) code, out, err = cli_runner(root) print(out) print(err) assert code == 0 assert out == expected assert "\r" not in out === END AC listing-full-output ===
