# FEATURE: Size Filter

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Drop zero-byte files and files smaller than the configured minimum size. |
| Depends On  | FEATURE-Walker.md |
| Provides    | scan.FilterSize |
| Consumes    | scan.Walk |

## Purpose

Remove files that can never be duplicates of interest before any contents are read.

## Behavior

- Exclude every file whose size is 0.
- Exclude every file whose size is smaller than the configured minimum; the default minimum is 1 byte.
- Operate as a pure function over the walker output.

## Programmatic Acceptance

```python
import subprocess
import tempfile
from pathlib import Path

RUN = ["go", "run", "./cmd/dupfind"]


def run_dupfind(target):
    return subprocess.run(RUN + [str(target)], capture_output=True, text=True, check=False)


def test_zero_byte_file_is_excluded_from_stdout():
    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        (root / "empty.bin").write_bytes(b"")
        proc = run_dupfind(root)
        assert proc.returncode == 0
        assert "empty.bin" not in proc.stdout


def test_non_empty_duplicates_survive_the_size_filter():
    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        (root / "empty.bin").write_bytes(b"")
        (root / "a.bin").write_bytes(b"same")
        (root / "b.bin").write_bytes(b"same")
        proc = run_dupfind(root)
        assert proc.returncode == 0
        assert "a.bin" in proc.stdout
        assert "b.bin" in proc.stdout
        assert "empty.bin" not in proc.stdout
```

## User Acceptance

- None.

## Guardrails

- The filter never reads file contents.

# FEATURE: Unreadable Files

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Skip an unreadable file with one stderr warning line, producing no stdout row and no exit-code change. |
| Depends On  | FEATURE-Grouping.md |
| Provides    | scan.Warn |
| Consumes    | scan.Group |

## Purpose

A file that cannot be opened or hashed must not abort the run.

## Behavior

- When a file cannot be opened or hashed, exclude it from grouping.
- Write exactly one warning line naming the file to standard error.
- Write no stdout row for the file.
- The warning does not alter the exit code.

## Programmatic Acceptance

```python
import os
import subprocess
import tempfile
from pathlib import Path

RUN = ["go", "run", "./cmd/dupfind"]


def run_dupfind(target):
    return subprocess.run(RUN + [str(target)], capture_output=True, text=True, check=False)


def test_unreadable_file_warns_once_and_exits_zero():
    if hasattr(os, "geteuid") and os.geteuid() == 0:
        return  # root reads mode-000 files; the precondition cannot be created
    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        locked = root / "locked.bin"
        locked.write_bytes(b"same")
        (root / "copy.bin").write_bytes(b"same")
        locked.chmod(0o000)
        try:
            proc = run_dupfind(root)
        finally:
            locked.chmod(0o644)
        assert proc.returncode == 0
        warnings = [line for line in proc.stderr.splitlines() if "locked.bin" in line]
        assert len(warnings) == 1
        assert "locked.bin" not in proc.stdout


def test_unreadable_file_does_not_block_readable_duplicates():
    if hasattr(os, "geteuid") and os.geteuid() == 0:
        return
    with tempfile.TemporaryDirectory() as tmp:
        root = Path(tmp)
        locked = root / "locked.bin"
        locked.write_bytes(b"same")
        (root / "a.bin").write_bytes(b"dup")
        (root / "b.bin").write_bytes(b"dup")
        locked.chmod(0o000)
        try:
            proc = run_dupfind(root)
        finally:
            locked.chmod(0o644)
        assert proc.returncode == 0
        assert "a.bin" in proc.stdout
        assert "b.bin" in proc.stdout
        assert "locked.bin" not in proc.stdout
```

## User Acceptance

- None.

## Guardrails

- The warning never changes the exit code.
