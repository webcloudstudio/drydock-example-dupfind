Purpose

This assembly story proves that the stories fit together. The supplied grader sources/run.sh builds ./cmd/dupfind, creates a fixed directory tree, and makes 15 checks of exit code and standard output. The grader is the exam: it is never modified, regenerated, substituted, or read by application code. A defect it exposes is fixed in the package that owns the behavior.

Assembly

All implementation stories are complete before this story runs: argument parsing, directory validation, walk, size grouping, digest grouping, group ordering, listing, summary, module build, and the test gate. This story adds no code of its own.

Reads

  • sources/run.sh, executed as a script only, from the application root.
  • bin/test.sh.

Writes

  • Nothing. The grader works in its own temporary directory.
