=== AC FEATURE-Duplicate-Finding.md :: duplicate-listing ===
Intent: A listing request succeeds and returns parseable CSV with the declared listing columns.
```python
import csv
from drydock_go import cli_runner

code, out, err = cli_runner(["."])
print(err)
assert code == 0
rows = list(csv.reader(out.splitlines()))
assert rows[0] == ["group", "size", "sha256", "path"]
```

=== AC FEATURE-Duplicate-Finding.md :: duplicate-min-size ===
Intent: The minimum-size option accepts a positive integer and rejects a nonpositive value.
```python
from drydock_go import cli_runner

code, out, err = cli_runner(["--min-size", "20", "."])
print(err)
assert code == 0

code, out, err = cli_runner(["--min-size", "0", "."])
print(err)
assert code == 2
assert out == ""
```

=== AC FEATURE-Duplicate-Finding.md :: duplicate-errors ===
Intent: Missing and extra arguments are usage errors; missing and non-directory paths are operational errors.
```python
from drydock_go import cli_runner

code, out, err = cli_runner([])
print(err)
assert code == 2
assert out == ""

code, out, err = cli_runner([".", "."])
print(err)
assert code == 2
assert out == ""

code, out, err = cli_runner(["./no-such-directory"])
print(err)
assert code == 1
assert out == ""

code, out, err = cli_runner(["go.mod"])
print(err)
assert code == 1
assert out == ""
```
=== END AC FEATURE-Duplicate-Finding.md :: duplicate-errors ===
