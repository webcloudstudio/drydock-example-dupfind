# FEATURE: Listing CSV

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Writes the duplicate listing as RFC 4180 CSV with the exact header `group,size,sha256,path`. |
| Depends On  | FEATURE-Grouping.md, ARCHITECTURE.md |
| Provides    | output.WriteListing |
| Consumes    | scan.Group |

## Questions

- None.

## Purpose

Render the duplicate groups produced by `scan.Group` as the default CSV listing on standard output.
This story owns the header, one row per file in every duplicate group, the lowercase hexadecimal
digest, and RFC 4180 quoting. Group ordering, path rendering, and group numbering belong to
FEATURE-ListingOrder.md. The empty listing belongs to FEATURE-ListingEmpty.md.

## Behavior

- `output.WriteListing` writes to an `io.Writer` using `encoding/csv`, with `\n` line endings.
- The first row is exactly `group,size,sha256,path`.
- Each file in each duplicate group produces one data row: group number, size in bytes, digest, path.
- The digest is lowercase hexadecimal SHA-256.
- A field containing a comma, a double quote, or a newline is quoted as RFC 4180 specifies.
- The writer accepts groups already ordered and numbered by FEATURE-ListingOrder.md and does not reorder them.

## Interface

- `output.WriteListing(w io.Writer, groups []scan.Group) error`

## Test Contract

The `internal/output` package carries one Go test per criterion below, named exactly as stated. Each
test builds real groups through the public interface and asserts the observed bytes or parsed fields.

# FEATURE: Listing Order

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Orders duplicate groups and their paths, numbers the groups from 1, and renders paths relative to the examined directory. |
| Depends On  | FEATURE-ListingCSV.md |
| Provides    | output.Order |
| Consumes    | output.WriteListing |

## Questions

- None.

## Purpose

Establish the deterministic order and the rendered path form that the listing and summary both
depend on. Groups are ranked by reclaimable bytes, then by digest. Paths are rendered relative to the
examined directory, so the listing is stable across runs and machines.

## Behavior

- Reclaimable bytes for a group equal `size × (files − 1)`.
- Groups are ordered by reclaimable bytes descending, then by digest ascending (lowercase hexadecimal, byte order).
- Groups are numbered from 1 in that order.
- Within a group, paths are ordered by byte value ascending.
- Paths are relative to the examined directory, use `/` as the separator, and carry no leading `./`.

## Interface

- `output.Order(groups []scan.Group, root string) []output.OrderedGroup`

# FEATURE: Summary

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Writes the --summary CSV totals computed from the same grouping the listing would produce. |
| Depends On  | FEATURE-Grouping.md, ARCHITECTURE.md |
| Provides    | output.WriteSummary |
| Consumes    | scan.Group |

## Questions

- None.

## Purpose

Report the number of duplicate groups, the number of duplicate files, and the reclaimable bytes for
the same options that produce the listing. The totals are derived from the same groups, so the
summary and listing never disagree.

## Behavior

- `output.WriteSummary` writes the header `groups,duplicate_files,reclaimable_bytes` and exactly one totals row, using `encoding/csv` with `\n` line endings.
- `groups` is the number of duplicate groups.
- `duplicate_files` is the sum of `files − 1` over all groups.
- `reclaimable_bytes` is the sum of every group's `size × (files − 1)`.
- With no duplicate groups the totals row is `0,0,0`.

## Interface

- `output.WriteSummary(w io.Writer, groups []scan.Group) error`

# FEATURE: Command Line

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Parses `[--summary] [--min-size <bytes>] <directory>` with options before the directory and maps usage errors to exit code 2. |
| Depends On  | ARCHITECTURE.md |
| Provides    | cli.Run |

## Questions

- None.

## Purpose

Own the command-line contract: argument parsing, the single required directory, the `--summary` and
`--min-size` options, and usage-error reporting. Directory existence checks belong to
FEATURE-TargetValidation.md. Scanning and rendering belong to their own features.

## Behavior

- `cli.Run(args []string, stdout, stderr io.Writer) int` parses arguments with a local `flag.FlagSet` configured with `flag.ContinueOnError`.
- Options are accepted before the directory: `[--summary] [--min-size <bytes>] <directory>`.
- Exactly one directory argument is required.
- An unknown option, missing or extra arguments, or a `--min-size` value that is not a positive integer returns exit code 2, writes exactly one line to stderr, and writes nothing to stdout.
- A valid invocation passes the parsed `summary` flag, `minSize` value (default 1), and directory to the injected execute function and returns that function's code.
- `Run` never calls `os.Exit`; only `cmd/dupfind/main.go` does.

## Interface

- `cli.Run(args []string, stdout, stderr io.Writer, execute func(opts cli.Options) int) int`
