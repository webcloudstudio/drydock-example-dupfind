# ARCHITECTURE: DupFind

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines the module structure and boundaries for the DupFind command-line application. |
| Provides    | ./cmd/dupfind |

## Questions

- None.

## Overview

DupFind is a read-only Go command-line application. The `./cmd/dupfind` package starts the process and delegates command behavior to internal application packages. It uses the Go standard library and the module declared in `go.mod`.

## Module Boundaries

| Module | Responsibility | Owns |
|---|---|---|
| `cmd/dupfind` | Process startup; invokes the CLI and exits with its returned status. | `main` |
| `internal/cli` | Parses options and arguments, validates the directory, coordinates discovery and output, and routes diagnostics to stderr. | CLI behavior |
| `internal/discovery` | Walks directories, identifies eligible regular files, hashes same-size candidates, and forms duplicate groups. | Discovery and grouping |
| `internal/output` | Orders duplicate groups and encodes listing or summary CSV. | CSV serialization |

The CLI receives arguments and the stdout/stderr writers from `main`. Discovery returns data to the CLI; output consumes those groups and writes CSV. Application packages do not read the supplied grader or write to examined directories.

## Module Ownership

| Boundary | Owner | Allowed low-level access |
|---|---|---|
| Persistence | None | DupFind has no persistent state or database. |
| Configuration | `internal/cli` | Command-line options only; no external configuration store. |
| File store | `internal/discovery` | Read directory entries and candidate file contents through the Go standard library. Never write, move, or delete examined files. |
| External services | None | No external services. |

## Technology Stack

| Technology | Use |
|---|---|
| Go | Go 1.22 or newer; application and tests use the standard library. |
| go test | Project test runner; `bin/test.sh` also runs `go vet ./...`. |
| Shell | POSIX `sh` for `bin/test.sh` and the supplied grader. |

## Guardrails

- Build the executable as `./cmd/dupfind` from the Go module root.
- Use only the Go standard library; do not add third-party modules.
- Keep the application read-only with respect to every examined directory.
- Do not read or depend on `sources/run.sh` from application code.
- Read file contents only when another eligible file has the same size.

# FEATURE: Command Interface

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines DupFind's command options, argument validation, and operational error behavior. |
| Depends On  | ARCHITECTURE.md |
| Provides    | dupfind command interface |
| Consumes    | ./cmd/dupfind |

## Questions

- None.

## Purpose

The command is `dupfind [--summary] [--min-size <bytes>] <directory>`. Options precede exactly one directory argument. `--summary` selects summary CSV output. `--min-size` takes a positive integer; files smaller than it are ignored, and the default is 1 byte.

## Behavior

- Accept options before the directory and reject unknown options, missing values, non-positive or non-integer minimum sizes, a missing directory argument, and extra arguments with usage exit code 2.
- A nonexistent path or a path that is not a directory exits with code 1.
- On success, return exit code 0 whether or not duplicates exist.
- On failure, write nothing to stdout and one diagnostic line to stderr.
- The process entry point is `./cmd/dupfind`; only `main` calls `os.Exit`. CLI behavior is exposed through `Run(args []string, stdout, stderr io.Writer) int`.

## Guardrails

- Do not print output to stdout for malformed arguments or invalid directory paths.
- Do not write diagnostic text to stdout.
- Do not change files in the directory being examined.

## Programmatic Acceptance

=== AC command-options ===
Intent: The command accepts the summary option and a positive minimum size before its directory argument.

# FEATURE: Duplicate Discovery

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines recursive, read-only discovery and grouping of duplicate regular files. |
| Depends On  | FEATURE-Command-Interface.md |
| Provides    | duplicate groups |
| Consumes    | dupfind command interface |

## Questions

- None.

## Purpose

Discover duplicate file groups beneath the selected directory. Two files are duplicates only when their byte contents match; size grouping followed by SHA-256 digest grouping implements this rule while avoiding reads for files with no same-size candidate.

## Discovery Rules

- Walk recursively, including hidden files and directories.
- Consider regular files only. Do not follow or report symbolic links.
- Ignore zero-byte files and files below the selected minimum size.
- Group candidates by size before opening file contents. Read contents only for sizes shared by multiple candidates.
- Hash candidate contents with SHA-256 and group files by digest within each size.
- A duplicate group contains at least two files with the same size and digest.
- If a file cannot be read, skip it and emit one warning line on stderr; this does not change the successful exit status.
- Discovery is read-only: it never deletes, moves, or modifies examined files.

## Programmatic Acceptance

=== AC recursively-finds-identical-files ===
Intent: Identical non-empty regular files in nested directories are recognized as duplicates.

import subprocess
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    payload = b"identical bytes"
    left = root / "left"
    right = root / ".hidden" / "right"
    right.parent.mkdir()
    left.write_bytes(payload)
    right.write_bytes(payload)
    result = subprocess.run(
        ["go", "run", "./cmd/dupfind", str(root)],
        capture_output=True,
        text=True,
    )
    print(result.stdout)
    print(result.stderr)
    assert result.returncode == 0
    assert len(result.stdout.splitlines()) == 3
=== END AC recursively-finds-identical-files ===

=== AC ignores-links-and-empty-files ===
Intent: Empty files and symbolic links do not contribute duplicate entries.

import subprocess
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    payload = b"target"
    target = root / "target"
    target.write_bytes(payload)
    (root / "link-a").symlink_to(target)
    (root / "link-b").symlink_to(target)
    empty_a = root / "empty-a"
    empty_b = root / "empty-b"
    empty_a.touch()
    empty_b.touch()
    result = subprocess.run(
        ["go", "run", "./cmd/dupfind", str(root)],
        capture_output=True,
        text=True,
    )
    print(result.stdout)
    print(result.stderr)
    assert result.returncode == 0
    assert len(result.stdout.splitlines()) == 1
=== END AC ignores-links-and-empty-files ===

# FEATURE: Listing Output

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines the default ordered CSV listing of duplicate files. |
| Depends On  | FEATURE-Duplicate-Discovery.md |
| Provides    | CSV duplicate listing |
| Consumes    | duplicate groups |

## Questions

- None.

## Purpose

On the default command path, emit one CSV row for every file in each duplicate group.

## Listing Contract

- Write CSV to stdout using the Go `encoding/csv` format and newline line endings.
- Always write the header `group,size,sha256,path`, including when no duplicates are found.
- Emit lowercase hexadecimal SHA-256 digests and paths relative to the examined directory.
- Use `/` path separators and omit a leading `./`.
- Order groups by reclaimable bytes descending, then digest ascending.
- Number groups starting at 1 in that order.
- Order paths within each group by byte value ascending.
- Reclaimable bytes for a group equal `size × (files − 1)`.
- Quote CSV fields as required for commas, double quotes, or newlines.

## Programmatic Acceptance

=== AC listing-header-and-empty-result ===
Intent: A directory without duplicate files produces a successful listing with only its header.

=== END AC listing-header-and-empty-result ===

=== AC listing-orders-paths ===
Intent: Listing includes each duplicate file and orders paths by byte value.

import csv
import io
import subprocess
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    payload = b"equal payload"
    names = ("z", "a")

    result = subprocess.run(
        ["go", "run", "./cmd/dupfind", str(root)],
        capture_output=True,

    assert len(rows[1:]) == 2

# FEATURE: Summary Output

| Field       | Value |
|-------------|-------|
| Version     | 20261024 V1 |
| Description | Defines CSV summary totals for the selected duplicate groups. |
| Depends On  | FEATURE-Duplicate-Discovery.md |
| Provides    | CSV duplicate summary |
| Consumes    | duplicate groups |

## Questions

- None.

## Purpose

When `--summary` is selected, emit one CSV data row containing totals for the groups that would be listed under the same minimum-size option.

## Summary Contract

- Write the header `groups,duplicate_files,reclaimable_bytes`, followed by exactly one totals row.
- `groups` counts duplicate groups.
- `duplicate_files` sums `files − 1` across groups.
- `reclaimable_bytes` sums `size × (files − 1)` across groups.
- With no duplicate groups, the totals are zero.
- Do not include files excluded by `--min-size`.

## Programmatic Acceptance

=== AC summary-empty ===
Intent: A directory with no duplicate groups returns zero totals successfully.

import csv
import io
import subprocess
import tempfile
from pathlib import Path

with tempfile.TemporaryDirectory() as tmp:
    root = Path(tmp)
    (root / "empty").mkdir()
    result = subprocess.run(
        ["go", "run", "./cmd/dupfind", "--summary", str(root / "empty")],
        capture_output=True,
        text=True,
    )
    print(result.stdout)
    print(result.stderr)
    assert result.returncode == 0
    rows = list(csv.reader(io.StringIO(result.stdout)))
    assert len(rows) == 2
    assert rows[1] == ["0", "0", "0"]
=== END AC summary-empty ===
