# FEATURE: Listing Report

| Field       | Value |
|-------------|-------|
| Version     | 20261023 V1 |
| Description | Emit deterministic CSV rows for duplicate file groups. |
| Depends On  | FEATURE-FILE-HASHING.md |
| Provides    | duplicate listing CSV |
| Consumes    | duplicate candidate grouping |

## Questions

- None.

## Purpose

The listing mode writes duplicate groups as CSV on standard output. It emits no data rows when no duplicate groups exist.

## Behavior

- Use `encoding/csv` with LF line endings.
- Emit `group,size,sha256,path` followed by one row per duplicate file.
- Order groups by reclaimable bytes descending, then SHA-256 digest ascending.
- Number groups from 1.
- Write relative paths with `/` separators and sort them by byte value.
- Preserve RFC 4180 escaping for commas, quotes, and newlines.
- Never write beneath the scanned directory.

## Programmatic Acceptance

=== AC listing-duplicate-rows ===
Intent: Duplicate files are emitted as parsed CSV rows with derived size and digest values.

import csv
import hashlib
import os
import tempfile
from drydock_go import cli_runner

with tempfile.TemporaryDirectory() as root:
    payload = b"same listing payload\n"
    paths = [
        os.path.join(root, "b", "copy.txt"),
        os.path.join(root, "a", "original.txt"),
    ]
    for path in paths:
        os.makedirs(os.path.dirname(path), exist_ok=True)
        with open(path, "wb") as handle:
            handle.write(payload)

    code, output, error = cli_runner(root)
    print(output)
    print(error)
    assert code == 0
    rows = list(csv.reader(output.splitlines()))
    header = ["group", "size", "sha256", "path"]
    assert rows[0] == header
    data = rows[1:]
    expected_size = len(payload)
    expected_digest = hashlib.sha256(payload).hexdigest()
    expected_paths = sorted(["a/original.txt", "b/copy.txt"])
    assert len(data) == len(expected_paths)
    assert [row[3] for row in data] == expected_paths
    assert all(row[0] == "1" for row in data)
    assert all(int(row[1]) == expected_size for row in data)
    assert all(row[2] == expected_digest for row in data)

| Consumes    | duplicate candidate grouping |

## Questions

- None.

## Purpose

Summary mode reports the number of duplicate groups, duplicate files beyond one retained copy per group, and reclaimable bytes.

## Behavior

- Emit `groups,duplicate_files,reclaimable_bytes`.
- Emit exactly one data row, including when no duplicates exist.
- Compute totals from the same duplicate groups used by listing mode.
- Apply the positive `--min-size` filter before forming totals.
- Write CSV with LF line endings.

## Programmatic Acceptance

=== AC summary-derived-totals ===
Intent: Summary values equal totals derived from duplicate files created by the criterion.

import csv
import hashlib
import os
import tempfile
from drydock_go import cli_runner

with tempfile.TemporaryDirectory() as root:
    groups = [
        (b"alpha", ["a.txt", "b.txt", "c.txt"]),
        (b"longer payload", ["d.txt", "e.txt"]),
    ]
    expected_groups = len(groups)
    expected_duplicate_files = 0
    expected_reclaimable = 0
    for payload, names in groups:
        for name in names:
            with open(os.path.join(root, name), "wb") as handle:
                handle.write(payload)
        expected_duplicate_files += len(names) - 1
        expected_reclaimable += len(payload) * (len(names) - 1)

    code, output, error = cli_runner("--summary", root)
    print(output)
    print(error)
    assert code == 0
    rows = list(csv.reader(output.splitlines()))
    assert rows[0] == ["groups", "duplicate_files", "reclaimable_bytes"]
    assert len(rows) == 2
    actual = [int(value) for value in rows[1]]
    expected = [expected_groups, expected_duplicate_files, expected_reclaimable]
    assert actual == expected
=== END AC summary-derived-totals ===

import csv
import os
import tempfile
from drydock_go import cli_runner

with tempfile.TemporaryDirectory() as root:
    small = b"tiny"
    large = b"large duplicate payload"
    for index in range(2):
        with open(os.path.join(root, f"small-{index}.txt"), "wb") as handle:
            handle.write(small)
        with open(os.path.join(root, f"large-{index}.txt"), "wb") as handle:
            handle.write(large)

    code, output, error = cli_runner("--summary", "--min-size", str(len(large)), root)
    print(output)
    print(error)
    assert code == 0
    rows = list(csv.reader(output.splitlines()))
    assert len(rows) == 2
    actual = [int(value) for value in rows[1]]
    expected = [1, 1, len(large)]
    assert actual == expected
