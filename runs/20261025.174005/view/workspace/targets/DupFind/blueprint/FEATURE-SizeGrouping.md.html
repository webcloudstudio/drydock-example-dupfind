FEATURE: Size Grouping

FieldValue
Version20261025 V1
DescriptionGroup candidate files by exact size and keep only sizes shared by two or more files, so unique-size files are never read.
Depends OnFEATURE-Walk.md, ARCHITECTURE.md
Providesdupes.GroupBySize
Consumeswalk.Files

Purpose

Rule 3 of the build instructions says files are grouped by size first and only files that share a size are read. This feature implements that first stage in internal/dupes.

Interface

dupes.GroupBySize takes the eligible files produced by walk.Files (relative path and size) and returns size buckets. Only buckets with two or more files are returned. The size is taken from the walk result; file contents are never opened in this stage. A file whose size is unique appears in no bucket and is therefore never opened for hashing.

Reads and Writes

  • Reads: the in-memory walk result only.
  • Writes: nothing.

Required Project Tests

The project test suite in internal/dupes contains TestGroupBySizeOmitsUniqueSizes (a unique size produces no bucket) and TestGroupBySizeKeepsSharedSizes (two or more files with one size produce one bucket holding all of them).

Intent: Files with a unique size are never reported and a shared size with identical contents is reported.
