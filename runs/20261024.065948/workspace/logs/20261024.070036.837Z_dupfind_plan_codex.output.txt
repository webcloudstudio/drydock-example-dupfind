## story duplicate-discovery
summary:      Discover duplicate regular files and emit ordered CSV listings or summaries.
type:         service
kind:         capability
phase:        1
implements:   FEATURE-Duplicate-Finding.md
covers:       DUPLICATE-DISCOVERY-001, DUPLICATE-DISCOVERY-002, DUPLICATE-DISCOVERY-003, SUMMARY-001, COMMAND-ERRORS-001
accepts:      st-004, st-005, st-006, st-007, st-008
context:      sources/INSTRUCTIONS.md
context_roles: |
  sources/INSTRUCTIONS.md: normative specification and conformance test suite
provides:     dupfind command
consumes:     ./cmd/dupfind
depends:       language-foundation
acceptance:   yes
instructions: |
  Implement the command contract in sources/INSTRUCTIONS.md. Parse options before the one required directory argument; distinguish usage errors (exit 2) from missing or non-directory paths (exit 1), with failures producing no stdout. Recursively walk hidden directories, skip symbolic links and zero-byte files, group by size before reading contents, hash same-size files with SHA-256, and warn once to stderr for each unreadable file while continuing. Apply the minimum-size filter consistently to listing and summary. Produce RFC-compliant CSV with relative slash-separated paths, bytewise path ordering, and groups ordered by reclaimable bytes descending then digest ascending. The summary reports counts and reclaimable bytes of those selected groups. Never modify examined files. Add focused Go tests for behavior and error paths.
