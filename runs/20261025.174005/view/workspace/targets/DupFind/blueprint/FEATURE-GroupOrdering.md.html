FEATURE: Group Ordering

FieldValue
Version20261025 V1
DescriptionCompute reclaimable bytes per group, order and number the groups, and order paths within each group.
Depends OnFEATURE-DigestGrouping.md, ARCHITECTURE.md
Providesdupes.Order
Consumesdupes.GroupByDigest

Purpose

Rules 4 and 5 fix how paths are written and how groups and paths are ordered so output is deterministic.

Interface

dupes.Order takes the duplicate groups and returns them ordered and numbered.

  • Reclaimable bytes of a group are size x (files - 1).
  • Groups are ordered by reclaimable bytes descending, then by digest ascending, and numbered from 1

in that order.

  • Within a group, paths are ordered by byte value ascending (plain string comparison).
  • Paths are relative to the examined directory, use / as the separator, and carry no leading ./.

Reads and Writes

  • Reads: the in-memory groups.
  • Writes: nothing.

Required Project Tests

internal/dupes contains TestOrder covering reclaimable-first ordering, digest tie-breaking, and byte-order paths.

=== AC order-reclaimable-beats-size ===
Intent: A smaller file with more copies precedes a larger file with fewer copies when it reclaims more bytes.

import csv import hashlib import os import tempfile from drydock_go import cli_runner

def write(root, rel, data): p = os.path.join(root, rel) os.makedirs(os.path.dirname(p), exist_ok=True) with open(p, "wb") as f: f.write(data)

large = b"L" * 10 small = b"s" * 3 large_paths = ["l1", "l2"] small_paths = ["s1", "s2", "s3", "s4", "s5"] assert len(small) * (len(small_paths) - 1) > len(large) * (len(large_paths) - 1) with tempfile.TemporaryDirectory() as root: for p in large_paths: write(root, p, large) for p in small_paths: write(root, p, small) code, out, err = cli_runner(root) print(out) print(err) assert code == 0 rows = list(csv.reader(out.splitlines()))[1:] assert rows[0][2] == hashlib.sha256(small).hexdigest() assert rows[0][0] == rows[len(small_paths) - 1][0] assert rows[len(small_paths)][2] == hashlib.sha256(large).hexdigest() === END AC order-reclaimable-beats-size ===
